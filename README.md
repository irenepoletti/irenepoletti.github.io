### 🛠️ Development

This site is built with React + Vite and GSAP, and deployed to GitHub Pages via GitHub Actions.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```
Site content (bio, experience, projects, etc.) lives in `src/data.js`. Pushing to `main` builds and deploys automatically via `.github/workflows/deploy.yml`.
